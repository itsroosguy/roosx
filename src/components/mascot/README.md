# Interactive Kangaroo Mascot Package

Production-ready interactive kangaroo mascot component built for web apps, landing pages, and hero banners.

## 📁 Included Package Files

- **`Body 1.png`** — Static torso anchor asset
- **`Head 1.png`** — Decoupled head layer asset
- **`eye balls.png`** — Registered pupil irises asset
- **`index.html`** — HTML5 standalone preview
- **`styles.css`** — Component CSS styles & backdrop gradient
- **`app.js`** — ES6 animation & vector clamping engine
- **`KangarooMascot.tsx`** — React / Next.js component
- **`KangarooMascot.module.css`** — CSS Module for React component

## 🚀 How to Run Locally

Open `index.html` in any browser or run a local HTTP server:
```bash
python3 -m http.server 8888
```
Then visit `http://localhost:8888`.
